# Ice Orchid · Call Operations Toolkit

I built three internal workflows for an outbound-calling operations team: call-record cleaning, supplier reconciliation, and phone-number label checks. The toolkit helped cut processing time for 160,000+ records from about an hour to under five minutes and surfaced a billing issue before invoicing.

[Try the interactive demo](https://binglan-number-check-demo.bellaaazhang.chatgpt.site/#prototype) · [Read the portfolio case study](https://app.notion.com/p/9bba7008facf82cb8d2001175c1011d2)

| Workflow | What you can try |
| --- | --- |
| Call-record cleaning | Load sample records and compare the results of two retention rules. |
| Supplier reconciliation | Compare two sample datasets and filter matched, mismatched, and one-sided records. |
| Number-label checks | Run a simulated batch check and filter the results by label status. |

The browser demo uses built-in sample data. The case study covers the original operational workflows and what changed after rollout.
